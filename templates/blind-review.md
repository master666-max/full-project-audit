# blind-review 盲判模板 v0.1（抽验防锚定污染）

> 用法：抽验者**先独立盲判、再对原判定答案**。锚定污染是主要误判通道（物理实验设计迁移：单盲）。

## 第一段：盲判（必须在对答案之前完成）

- 抽验任务 id：｜ 被抽验判定编号：
- 请重读原始仓库代码（不看原报告的判定与摘录），独立给出：
  1. 判定：PASS / FAIL / N/A
  2. 摘录（整函数/整块）：
  3. 若 FAIL：独立核验路径（命令/输入/预期输出）
  4. 反证记录（若判 PASS）：

## 第二段：对答案（盲判完成后填写）

- 原判定：PASS / FAIL / N/A ｜ 原证据级别：
- 三核对：行号真实？摘录单元完整？反证记录与结论相容？
- 盲判一致性：一致 / 不一致（不一致逐项列差异与归因）
- 一致性统计入终报：盲判不一致率 >20% → 原判定存在锚定污染收益（转核心审计）；>95% → 冗余（退役）。
